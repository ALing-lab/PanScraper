## 123 网页登录白屏

旧首选地址 `https://www.123pan.com/login` 存在异常跳转，`login.123pan.com` 探测返回 404；公开浏览器探测中部分官方云盘页出现远端 bootstrap 脚本错误和空内容，不能将这些外部异常都归因于本机 Android16。

本轮改为官方 HTTPS 根入口，保留设备真实 Chromium 版本，平板默认使用电脑网页布局，并可切换手机版。增加官方线路切换、主文档 HTTP/网络/证书失败提示、超时处理和 DOM 空白检测；限定 WebView 显示范围，原生返回/刷新/提示栏保持可见；处理渲染进程退出及 View 销毁，补齐 cn 域名 Cookie 读取。

没有放开非官方主文档、证书错误或混合内容。读取到的登录状态仍须通过 123 API 验证后才保存。公开探测未登录真实账号。新增登录入口/UA/官方域名测试和横屏平板原生控件可见性测试。

**尚未在用户的一加平板 Pro / Android16 上安装复测，不能保证所有官方网页故障均已消除。** 修复包安装后优先验证网页登录；若线路仍白屏，保留顶部具体提示便于继续定位。

## 其他改进

- 保留上游 main 的正式包测试钩子隔离、预览汇总性能、holderOf、防明文固定域名及对应测试。
- 使用 Navigation 公开返回栈接口，修复 RestrictedApi Lint 错误。
- Android15 dataSync 前台服务达到系统超时回调时保存暂停并停止服务；回调逻辑有本地测试，真实系统长时间后台行为仍需真机验证。
- WebDAV XML 与通用 fetch API 响应限制 8MB，拒绝 DTD/ENTITY 声明。
- 依赖升级到维护分支 at.yawk.lz4:lz4-java 1.14.0、Bouncy Castle 1.87。重新查询95个解析运行时组件，OSV 未返回版本匹配，查询0错误；数据库无命中不等于无漏洞。

## 验证结果

最终全套测试：396 项，388 通过、8 跳过、0 失败；Lint：0 Error、28 Warning、4 Information。正式 Release 压缩/混淆构建成功，非调试包；APK v2、v3 签名验证通过，签名证书与用户提供的 JKS 一致，zipalign 验证通过。另有3个独立 Chromium DOM 空白检测检查通过。

最后一次并行验证曾出现一项 ScreenshotTest.dataConfirmLight 界面空闲超时，当时观察到构建机内存压力；释放空闲编译进程并分开构建与完整测试后未再复现。保留失败记录在 test-evidence/repair-verification-retry，最终独立复跑结果在 test-evidence/repair-final，不删除这次失败记录。

首次全量回归发现的 115 用例失败来自假服务器没有模拟成功上传后的文件落盘，已补齐服务器行为，并增加未确认上传必须失败的反向测试。历史旧用例按“复用匹配并检查缺失操作”更新，原有缺失元数据回归保留；没有通过删除安全断言掩盖错误。

8个跳过项依赖外部服务/环境，未作为通过计数。本轮没有再次对用户真实网盘执行写操作。自动化测试主要使用 Robolectric SDK34、MockWebServer 和内存网盘，不等同于真实 Android16/123/115 全链路验证。

## 保留的边界与后续验证

用户自填 HTTP WebDAV 的明文传输风险仍存在；旧 Android8/9 专属外部目录的数据隔离仍有平台限制。本轮没有宣称这两项已消除。正式签名与 SHA-256 校验用于确认交付完整性，不能替代真机兼容性和业务验证。
